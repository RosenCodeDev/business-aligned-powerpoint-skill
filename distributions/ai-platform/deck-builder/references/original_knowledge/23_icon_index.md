# Icon Index — concept names the GPT can use

Curated OW icon set (~500 line icons, navy/Text 1, native editable freeforms).
**Type any concept word below as an `icon` value** — the runtime resolves it to the
right icon (Heroicons-style names like `chart-bar`, `light-bulb`, `device-phone-mobile`,
`user-group` also resolve via the alias map). Prefer a word from this list; if you use
one that isn't here, the resolver still falls back to the closest match, but a listed
word is guaranteed. Item icons are all-or-nothing: give EVERY `show_columns` column and `dashboard` KPI an icon, or none — if any one is missing or unresolvable the runtime shows none on that slide.
